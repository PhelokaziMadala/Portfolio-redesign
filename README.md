# Phelokazi Madala Portfolio

This is my upgraded personal portfolio, transitioned from an earlier static version to a modern React + TypeScript application.

The portfolio presents my profile, technical and soft skills, education, experience, certificates, group and personal projects, and contact information in a cleaner, more interactive UI.

## Transition Summary

This project was transitioned and improved with:

- Migration to a component-based React architecture
- Type-safe development using TypeScript
- Modern Vite development/build tooling
- Updated UI styling and layout consistency across sections
- Enhanced content structure and readability

## Major Updates Implemented

- Reworked Experience section with corrected dates and detailed responsibilities
- Expanded About Me section with a fuller professional summary
- Split skills into separate Technical Skills and Soft Skills sections
- Improved Certificates section into a clearer list format
- Restored and reorganized Projects into Group Projects and Personal Projects
- Expanded project descriptions with better context and technologies used lines
- Updated project order to show most recent group projects first
- Added demo icons for all View Demo links
- Connected Download Resume button to the latest uploaded PDF
- Redesigned Get In Touch section with improved card-based UI
- Added clickable contact links (email, LinkedIn, GitHub) using React icons
- Embedded location map with current location label: Delft, Cape Town
- Improved contact form UX:
  - Sends to Formspree without redirect
  - Shows success/error toast message
  - Auto-hides message after 5 seconds
- Rebuilt chatbot into a floating corner widget with:
  - Compact modern chat UI
  - Instant answer buttons (Skills, Experience, Projects)
  - Better natural-language intent matching
  - Typing indicator
  - Auto-scroll to latest message
  - Clear chat action
  - Enter-to-send and Shift+Enter newline behavior

## Project Setup

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Run lint checks

```bash
npm run lint
```
